Sometimes the best way to improve an old system is to replace it.

Foresight Research's website was running on an outdated WordPress installation that had become increasingly difficult to maintain.

It was slow, poorly suited to mobile devices, and looked like it belonged to a different era of the internet.

The aging WordPress and PHP setup had also experienced recurring security problems.

So I rebuilt it from scratch.


I handled the entire rebuild myself, from designing the interface and implementing the frontend to configuring deployment and documenting the project.

The website uses static generation, producing prebuilt files that can be served without a continuously running application backend.

I set up GitHub Actions to build and deploy the website automatically.

I documented the project's structure, development environment, deployment process, and maintenance procedures.
